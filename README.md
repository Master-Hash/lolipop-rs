# lolipop-rs

一款 Vibe coding 实验项目，旨在检验 Rust 编译器能否对抗 AI 幻觉，顺便用 Windows Composition API 为 Emacs 画好看的光标特效动画。

## 参见

[pop-select (Rust)](https://github.com/lynnux/pop-select/blob/master/src/beacon.rs)：采用独立 UI 线程和 GDI 动画，现已过时。
[lolipop (Objective-C)](https://github.com/RadioNoiseE/lolipop/blob/main/lolipop.m)：采用 AppKit。本项目采用相同的 Elisp 文件和 C ABI。
